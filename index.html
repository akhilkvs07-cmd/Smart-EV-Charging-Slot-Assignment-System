How the algorithm decides

Same core logic as the C++ implementation.

01
Calculate each EV's priority

Low battery, waiting time, reservation and emergency affect the score.

02
Process highest priority first

Ties: longest wait first, then the smaller EV ID.

03
Find the best compatible station

Only available stations with the same connector qualify; among them, choose the highest power.

04
Assign or leave waiting

The station becomes occupied after assignment. If no match exists, the EV remains in the waiting list.
